# 三層架構，一次看懂

這一頁講清楚 agsy 的核心設計。看懂這一頁，其他所有行為都能推理出來。

## 三層架構

```
【來源層】原稿，你唯一要編輯的地方
    ~/all-ai-lib/      ← 跨專案共用庫
    ./repo-ai-lib/     ← 專案自己的庫（要幾個來源有幾個，順序 = 優先級）
         │
         │  build =「複製 + 合併」
         ▼
【產物層】合併結果
    .agsy/             ← 隨時可以砍掉重建的副本（附 manifest 記帳本）
         │
         │  mount =「建立目錄連結」
         ▼
【掛載層】工具實際讀取的地方（裡面是連結，不是真檔案）
    .claude/rules  ──→ 指向 .agsy/rules
    .agents/workflows → 指向 .agsy/workflows/agents
```

三個重點，記住就懂一半：

- **build 是「複製」**——來源永遠不會被工具直接碰。`.agsy/` 是用完可丟的副本，
  砍掉重跑 `apply` 就原樣長回來。
- **mount 是「連結」**——`.claude/`、`.agents/` 裡放的是指向 `.agsy/` 的目錄連結
  （macOS/Linux 用 symlink，Windows 用 junction、免特權）。
  工具讀 `.claude/rules/`，實際讀到的就是 `.agsy/rules/`。
- **AI 改了掛載端的檔案，髒的是產物層**——來源結構上不可能被污染。
  想留的改動用 `promote` 寫回來源；不想留，下次 `apply` 重建就沒了。

## 為什麼要多一層產物層？

單層同步（來源直接連到工具目錄）有個隱藏炸彈：AI 工具在掛載位置改檔案時，
改動會**直接穿進你的原稿**——如果那是跨專案共用庫，等於污染了所有用它的專案。

agsy 刻意在中間加一層：

```
   來源（原稿）────────── 任何工具都碰不到
      │  build = 複製
      ▼
   .agsy/（可拋棄的沙盒）◀──── AI 的改動落在這裡，也停在這裡
      │  mount = 連結                │
      ▼                              │ 想留 → promote 寫回來源
   .claude/  .agents/                │ 不想留 → 下次 apply 重建掉
```

這一層買到的性質全是連動的：「來源永遠乾淨」變成結構保證而不是自我約束；
分流在 build 時就完成，掛載層簡單到只是「一個目錄一條連結」；
產物永遠可重建，所以 `clean` 能做到完整、安全的反安裝。

## 雙向同步

```
  apply:    來源 ──（重建產物 + 掛載）──▶ .agsy/ ◀──（連結）── .claude/ .agents/
  promote:  來源 ◀──（把改動寫回原家）── .agsy/
```

兩個指令、兩個方向：`apply` 往右推（來源是真理），`promote` 往左收（把值得留的改動接回家）。
`status` 負責告訴你現在哪個方向有落差（詳見[日常使用](daily.md)）。

## manifest：讓一切可追溯的記帳本

每次 build 會在 `.agsy/` 裡寫一份 manifest，記下每個檔案的
內容指紋（sha256）和**它從哪個來源來**。有了它：

- `status` 能分辨「來源變了」還是「產物被改了」，還能指出被改的檔案原家在哪
- `promote` 知道每個改動該寫回哪裡（被改名過的檔案也能自動還原原名）
- 目錄型的 skill 能精確到「哪幾個檔案變了」

## 安全底線

這幾條是 agsy 全部指令共同遵守的規矩：

- **絕不刪除任何「不是它自己建立」的東西**——連結是工具建的，可以砍掉重建；
  你的真實目錄和檔案一律報錯請你自己處理，絕不代刪。
- `build.out`（產物目錄位置）有防呆——指到專案外、家目錄、來源路徑都會在讀設定時直接擋下。
- `apply` 動手前一定先檢查有沒有未回寫的改動，不會無聲覆蓋。
- `plan` 保證不寫入任何檔案——先看再跳。

?> **一個要知道的例外**：manifest 只追蹤 build 放進產物的檔案。AI 在掛載端**新增**的檔案
（不是修改既有檔案）沒有原家、promote 回寫不了——status 會列為「未追蹤」，
apply 會先問過你才刪。AI 幫你新寫的 rule/skill 想留下來，請手動搬進來源資料夾再 apply。

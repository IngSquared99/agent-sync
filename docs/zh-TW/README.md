# agent-sync（agsy）說明文件

agsy 的完整使用說明，依「安裝 → 快速上手 → 深入教學 → 疑難排解」的順序編排。
網站左側側欄可瀏覽全部章節，右上角搜尋框可全文檢索；在 GitHub 上瀏覽時，直接點下表的檔案連結即可。

## 建議閱讀路徑

- **第一次使用**：核心概念 → 安裝說明 → 快速上手，跑完 `init → plan → apply` 後再回頭看設定檔與指令說明。
- **想搞懂設定檔每一行**：設定檔 agsy.yaml。
- **某個指令的行為跟預期不同**：指令說明的對應小節、情境全覽，以及 Q&A。
- **想接新的 AI 工具**：適配器。
